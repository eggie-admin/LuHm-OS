# Project Premonition | Illustrated game manual (review draft)

Open [the manual preview](index.html) as HTML or serve this directory with `python3 -m http.server`. This is a **review-only layout**, not a published GitHub Pages site.

## What is in this edition
- Accessible, responsive gothic game-manual layout with character cards.
- Professor's four modes, Urd, Belldandy, Skuld, Lum, Yume, and reserved slots for Mom and the Yonis.
- Riverwalk, Crown Cathedral, and Coffee House concept entries.
- Clearly labeled source/prototype links and art-proof limitations.

## Art promotion gates
1. Locate the real lineup image bytes in owner-controlled Drive.
2. Confirm original authorship, license and permission for **each** image; do not infer approval from a character-bible text file.
3. Confirm Mom and Yonis names, appearances and narrative roles with their original Canon.
4. Export optimized web derivatives with alt text and provenance, keeping source files private.
5. Replace typographic concept cards with approved thumbnails.
6. Request owner review of the visual result before merging or enabling public Pages.
7. Preserve the separate Android signing and Crown STOP gates.

Source reference: LuHm Art Magic Character Bible v0.1 (Professor-approved visual lane, **not** automatic public-publish approval). ArtAssets README explicitly states `publicApproved:false` for inventoried assets.
