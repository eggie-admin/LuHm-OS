## Visual law

1. A compact Ubuntu MATE-inspired top desktop panel.
2. A full-screen 3D Lum companion surface as the dominant visual layer.
3. Bottom-docked translucent chat, approximately 30% of screen height.
4. The 3D companion scene occupies approximately 70% of the screen.
5. Minimal navigation and low chrome.
6. A single explicit backend/system-layer control rather than backend tools mixed into chat.
7. Dark cyber-gothic palette with restrained magenta/cyan highlights.

The binary mockup is a design reference, not a runtime dependency. Runtime code reserves the `data-luhm-lum-viewport` mount for the real 3D renderer.
