# contextTourniquet v1

Purpose: bound chat/app memory so stale conversation cannot become doctrine, source truth, GREEN state, approval, or execution authority.

## Precedence

1. current explicit Professor instruction
2. canonical source at exact sourceRef
3. sealed doctrine and deterministic receipts
4. bounded task checkpoint
5. conversation history and model memory

Lower layers may provide leads but may not override higher layers.

## Flow

`ingest -> classify -> reconcile -> clamp -> checkpoint -> criticGate -> professorCrown -> toolExecutor`

## Claim classes

`PROVEN | SOURCE_DERIVED | OBSERVED | INFERENCE | PROPOSAL | MEMORY_ONLY | UNKNOWN | CONTRADICTED`

No evidence means no factual claim. Historical GREEN never implies current GREEN.

## Tourniquet triggers

Clamp context when any of these occurs:
- sourceRef changes
- doctrine or canonical path changes
- evidence conflicts
- context budget is exceeded
- an agent handoff occurs
- task approaches merge, CAST, publication, signing, deletion, deployment or device mutation
- a claim attempts to move toward GREEN without deterministic proof

## Memory write law

Agents may propose memory/checkpoint changes. They may not silently promote chat text, summaries, personality output or their own conclusions into persistent doctrine.

## Authority

Lum orchestrates. Context, Build and Research are bounded workers. Critic checks contradictions independently. Tool Executor executes only an authorized deterministic action. Helpers do not recruit helpers.

Professor retains Crown.

## Urd mutation-review lane

Urd is a required bounded reviewer whenever a checkpoint contains a proposed mutation, a sourceRef transition, a memory/source conflict, rollback planning, cross-layer impact, or an approaching Crown boundary.

Urd applies `agents/urdMutationOni/SKILL.md` plus the shared systems practice. She traces dependencies, exposes second-order effects, designs rollback boundaries, and checks whether remembered state is being mistaken for current source state.

Urd's review may return `watchStop` or a proposed mutation plan. It is not approval. She may not mutate, execute, merge, CAST, publish, sign, delete, self-approve, grant Crown, or promote memory into doctrine.

The flow for mutation-bearing checkpoints is:

`contextTourniquet -> Urd mutationReview -> Critic contradictionCheck -> professorCrown -> ToolExecutor`
