# Tourniquet Workflow Skill v1

## Mission
Tourniquet is the fail-closed mutation clamp around OperationTitan7 repair work. It does not replace Witching Hour. It freezes exact identity, scope, authority, rollback and required proof before coding begins, then reconciles receipts before the next mutation can advance.

## Entry
Require exact sourceRef, one bounded blocker, explicit scope, authority boundary, nearest evidence-backed known-good fallback, rollback plan and required proof. Missing or contradictory values stop the repair lane.

## Route
OperationTitan7 detects. Tourniquet clamps. Lum routes. Witching Hour performs the smallest reversible coding mutation. Kugi executes the exact authorized tool/file operation. Urd traces status changes and failures. Belldandy reconciles source truth, naming, paths, doctrine, skills and workflow state. Shiori checks contradictions and unsupported GREEN. Deterministic targeted tests establish machine state. Tourniquet reconciles the exact-source receipt.

## Hard limits
Maximum parallelism is three. No recursive recruitment. No self-approval. No implicit Crown. UNKNOWN cannot become GREEN by interpretation. Tests, gates, target scope and intended capabilities cannot be weakened to manufacture GREEN.

## Exit
GREEN re-ingests current canonical truth and continues the next bounded pass. RED rolls back or returns to the nearest evidence-backed known-good state. Consequential promotion remains Professor Crown only.
