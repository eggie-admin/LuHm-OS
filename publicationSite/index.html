LuHm OS

LuHm OS is a read-only, evidence-gated developer plugin. It exposes bounded MCP tools for source-truth inspection, Lum/Oni role discovery, scope validation, deterministic read-only routing, and proof-contract inspection.

The public plugin does not expose merge, publish, destructive-delete, production-signing, checkout, secret-write, or infrastructure-mutation tools.
