LuHm-OS is an independent, artist-first creative software project by Eggie Bagelface. Project Hydra combines playful character interfaces, Godot experiments, media tooling and evidence-led software engineering without enterprise overhead.

What we're building

Artist's workbench

Blender, FFmpeg, Godot and web UI components for storyboards, animation, accessible controls and reproducible media workflows. Features are developed and verified individually.

Safe agent workflows

Source-linked tasks, permission boundaries, read-only inspection tools, transparent test results and controlled deployment. Role names are workflow labels, not claims of autonomous agents.

Defensive software practice

We study application security, privacy, secrets management, dependency checks, asset provenance and human-authorized remediation on systems we own or are permitted to test.

Publicly available today

The LuHm-OS GitHub repository contains the public project source, documentation, tests and proposed architecture. This site publishes a public alpha release statement and policy pages.

Some demonstrations are prototypes, some features are source-only, and personal media or donor assets are not published. A private ChatGPT plugin exists separately; it is not a public-directory approval. OpenAI Daybreak access, participation and endorsement are not claimed.

Independent by design

Built for personal creative projects and small-business possibilities. We prefer lean hosting, direct GitHub workflows, local-first media work, accountable public claims and simple release proofs.
