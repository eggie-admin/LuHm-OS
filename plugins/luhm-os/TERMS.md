# LuHm OS Plugin Terms

Status: development candidate. This document does not authorize publication or production use.

LuHm OS is provided under the repository license and is intended for evidence-gated development workflows.

## Human authority

The plugin may inspect, route, summarize, and prepare evidence. It does not independently authorize production signing, publication, protected-branch promotion, public exposure, destructive deletion, or secret writes. Consequential actions remain human-controlled.

## Evidence

Tool results and AI output are not guarantees. GREEN claims require evidence matching the exact source, scope, and proof gate. UNKNOWN remains UNKNOWN.

## Security

Do not put API keys, signing material, private keys, bearer tokens, or other production secrets in the plugin package, prompts, public repository, or Android client.

## Availability

The development plugin may change without notice. A published version requires separate hosting, privacy, security, reliability, and submission review.
