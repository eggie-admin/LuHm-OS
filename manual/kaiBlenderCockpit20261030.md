# Kai Blender Forge: GParted to npm to ChatGPT

2026-10-30. Source candidate; no active agents, hardware writes, secrets, or publication.

## 4x4 composition and headless pathway
The canonical four package layers are coreLibrary, pluginExtension, classWidgetOrganization, and stubAdapterBoundary. Hear/Resolve/Act/Verify is a separate control rhythm. Escalation levels 0 through 3 remain independent.
GParted is a Linux GUI for operator-approved disk work, never the backend. Start with read-only lsblk. Python3 and parameterized SQLite STRICT are the lean control and receipt layer. The web UI cannot issue arbitrary SQL, partition operations, shell commands or model calls.

## Blender, Godot and approved Meshy asset intake
Blender is a separately installed, optional headless Linux studio tool. Use Blender --background with a reviewed local scene only; no auto-enabled extensions or paid cloud generation.
The existing tools/yumeGodotAssetPrep.py is the asset intake gate. For a candidate GLB or PNG, prepare its manifest with SHA-256, sourcePath, contentLane, publicAllowed, licenseEvidence, creatorCredit, provenance and professorApproval. Even its GREEN_PLAN_ONLY status is not build/import/publication proof.
Meshy's official Blender addon requires Blender 4.2.6 or newer and Meshy Pro for its DCC Bridge. Linux is not officially supported. Manual user-approved GLB import is the platform-neutral path. The add-on and provider credentials are not bundled.
Meshy Free outputs are generally CC BY 4.0 with required attribution; paid output ownership differs. Community uploads and derived references have separate provenance concerns. Do not assume commercial rights make add-on binaries or private asset files redistributable.
The community Blender MCP tool can execute Python inside Blender. Keep it uninstalled and disconnected from the public cockpit until sandbox, permission, licensing and independent safety tests prove a bounded implementation.

Use frontEnd/prototypes/glassWorld: npm ci --ignore-scripts --no-audit --no-fund and npm run check. The existing isolated Babylon/Vue/jQuery demo uses a locked build. Node and npm are build-time only.
