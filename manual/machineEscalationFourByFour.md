## Five and twelve audits
Use a **five** check quick pass for bounded daily machine preflight. It executes current source audits: escalation kernel, network spine, offline GitHub governance policy, agent quarantine policy and Operation Titan7 Final Form contract.

Use a **twelve** check extended pass for repair/release preparation. It repeats those five and adds: Cloudflare edge source policy, storage topology, plugin publication source, Render edge source, ten-pass security doctrine, Titan7 current canon inventory, and 200-pass hard-system source audit. Both bundles are existing deterministic Python checks, NOT five or twelve AI agents. The second bundle does not run live DNS, Cloudflare account APIs, paid inference, production SQL, device installs, Certbot or deployments.

Use exact-source scripts from a clean committed checkout:
```bash
SHA=$(git rev-parse HEAD)
python3 -m unittest discover -s tests -p testMachineEscalationFourByFour.py -v
python3 tools/machineEscalationFourByFour.py --source-ref "$SHA" --depth five --titan-tier 0
python3 tools/machineEscalationFourByFour.py --source-ref "$SHA" --depth twelve --titan-tier 0
```
The tools are fixed allowlists. A malicious prompt or audit manifest cannot introduce a shell command. The receipt stores outcome and SHA-256 of output, **not raw logs or secrets**. The output status `GREEN_SOURCE_ONLY_EXTERNAL_HOLD` is not merge/deploy/host/device/protective-security/Crown GREEN.

## Reaper and failure doctrine
"Chop the head off the reaper" has **no existing source-defined operational meaning** in present canonical GitHub search. Here it is a proposed friendly label for *stop the stale or failing candidate*, preserve the entire evidence trail, isolate the single smallest broken gate, plan rollback, then generate a new reviewed source candidate. **Never kill a production service, purge an artifact, reset history, force-push or destroy backups** because that phrase is spoken.

If a failure occurs: `RED_OR_UNKNOWN_SOURCE_STOP`; hold and diagnose, and if authorized do one bounded repair on a new commit. Rerun the affected audits and the 4x4 exact-source preflight. If actual human/physical/cloud permission is missing, report one actionable blocker rather than inventing a GREEN result.
