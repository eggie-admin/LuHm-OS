# LuHm-OS: Project Premonition | Funding and release one-pager
**Status:** editable **draft** for Professor approval. **NOT a public campaign or evidence of committed funding.**

## What is being created
**LuHm-OS: Project Premonition** is an independent, artist-led game and moving-image production toolkit. The Professor creates original interactive environments, character performances and short-form video by connecting a lightweight Samsung Android cockpit to a Linux creative studio. The public-safe project source is maintained under `eggie-admin/LuHm-OS`; unpublished original art remains private.

## Product experience we're working toward
A Samsung tablet opens a real interactive **Babylon.js** 3D stage; **Vue 3 and jQuery** present object placement, scene inspection and controls. **Godot 4** concentrates on high-resolution character expressions and animation. **Blender** makes editable masters. **Python** validates tasks, ownership and receipts, while **FFmpeg** generates clips and **VLC** may supply enhanced local media playback. **This is an architectural goal, not a claim that a production APK or live dual-renderer avatar is already working.**

## Evidence already in source
- A browser-build candidate supports placing, selecting, moving, removing and locally saving primitive Babylon 3D objects. GitHub CI source tests and a locked npm build passed at the referenced review.
- Dedicated Godot 4 transparent avatar viewport source exists; a physical Samsung alpha-composited character has **not** been verified.
- A signed Android beta build workflow and private F-Droid staging scripts exist. A real current owner-signed APK, signed repository index, phone installation and same-signer upgrade remain **unverified**.

## Funding thesis
Build one short **playable, rights-cleared demonstration** that proves the original creative direction and a reproducible production process. Seek support for **original character design and rigging, asset production, QA/device testing, accessibility, documentation and modest distribution expenses**. Budget amounts, terms, delivery schedules and funding targets require the Professor's explicit numbers and approval. No sponsor, grant, or partnership is claimed.

## Four proof milestones
1. A verified playable Samsung scene including touch, save/reload, stable assets and measured memory/FPS.
2. A commissioned or Professor-approved original high-fidelity character, with demonstrable expressions, hair and animation.
3. A short original video capture created through a rights-cleared Blender/Godot/FFmpeg workflow and auditable asset receipts.
4. Owner-signed APK and update continuity, then an independently signed HTTPS F-Droid repository or another authorized installer. The public site and F-Droid client catalog are independent steps.
