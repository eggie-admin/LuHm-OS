## PROFESSOR LECTURE

Recurring vocabulary: Forge = build environment. Crown = consequential human authority. Seal = recorded verified state. Receipts = evidence. Spaghetti temple = messy architecture with unclear structural dependencies. Haunted toaster = suspicious machine behavior. Green crayon = unsupported success claim.
Useful correction commands: SANITY CHECK. SOURCE OF TRUTH. AUDIT. MUTATE. PROVE IT. SEAL. PARK IT. JUST BUILD THE FUCKING TOY.
The correction protocol is short: stop, restate corrected target, discard invalid assumption, recalculate the next safe action, continue. No twelve-paragraph apology. Fix the work.
