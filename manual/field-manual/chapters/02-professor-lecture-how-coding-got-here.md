## Professor Lecture

Human-centered coding begins with models, decomposition, naming, testing, and judgment. Those skills do not disappear when tooling improves.

Scripted languages made repeatable automation practical. Unix-style pipelines taught generations of developers to combine small tools through clear inputs and outputs.

Python 3 is useful because it is readable, composable, automation-friendly, and surrounded by a huge ecosystem. It is glue, not magic.

AI-assisted development can draft, compare, explain, prototype, search, and transform code. The sane approach is not 'no thinking.' It is less mechanical typing and more explicit intent, review, testing, and policy.

## Lum Tech Demo / Field Notes

- Prefer small composable tools over giant opaque ones.
- Keep inputs and outputs inspectable.
- Keep provider boundaries explicit.
- Treat generated code as a candidate until tests and review support it.
- Use automation to amplify judgment, not replace it.
