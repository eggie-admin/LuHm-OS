## Professor Lecture

Witching Hour is a structured roleplay wrapper around the same disciplined workflow. It makes the interaction memorable without weakening policy.

The ritual prepares a build. It does not bypass review, policy, security, testing, or Crown authority.

Persona/game inspiration may shape pacing, menus, scene transitions, and vocabulary. It does not change the engineering contract underneath.

## Lum Tech Demo / Field Notes

- 1. DEFINE GOAL - one sentence.
- 2. GATHER SOURCE OF TRUTH - real files, commits, docs, receipts.
- 3. STATE CONSTRAINTS - boundaries before generation.
- 4. DRAFT PLAN - steps, tools, tradeoffs.
- 5. AUDIT - policy, evidence, security, architecture.
- 6. HUMAN APPROVAL - edit or approve.
- 7. RUN - execute only the authorized plan.
- 8. TEST + RECEIPTS - prove what happened.
- 9. GATE + SEAL - record exact state.
