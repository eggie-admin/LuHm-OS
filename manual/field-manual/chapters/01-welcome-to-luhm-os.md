## Professor Lecture

LuHm OS is the product. Project Hydra is the development and testing codename.

The project is built around people, tools, intent, and evidence. AI is allowed to be clever. It is not allowed to invent authority.

The learning loop is Quest -> Scout -> Plan -> Mutate -> Test -> Collect Receipts -> Gate -> Seal.

The manual's voice is deliberately human. Use short sentences. Use complete thoughts. A joke may introduce a lesson. The technical meaning follows immediately.

## Lum Tech Demo / Field Notes

- Quest: state the actual goal.
- Scout: inspect source, current state, dependencies, and real artifacts.
- Plan: choose the smallest safe change and define rollback.
- Mutate: make one intentional change.
- Test: run the test that matches the claim.
- Receipt: save evidence that supports exactly that claim.
- Gate: GREEN, AMBER, RED, or UNKNOWN.
- Seal: record verified state and the next safe action.
