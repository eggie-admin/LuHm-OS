# 10 // One Hydra, Different Bodies

*Compute escalation changes resources, not authority.*

## Professor Lecture

Tier Zero handles tiny local intent, routing, device state, and simple cached behavior.

Tier One mobile devices handle UI, pet/voice interaction, sensors/media, lightweight inference, authentication, approved device actions, and handoff.

Tier Two medium machines handle fuller agents, backend services, database work, Git, FFmpeg, moderate rendering, and development builds.

Tier Three desktops handle large local models, simultaneous agents, Android/Linux builds, Blender, Godot, long-context work, and heavy artifact generation.

Compute size never increases permission. A bigger machine does not outrank Professor or policy.

## Lum Tech Demo / Field Notes

- Small when it can be.
- Mobile when it should be.
- Local when it makes sense.
- Huge when the job deserves it.
- Never make the haunted toaster render Blender.
