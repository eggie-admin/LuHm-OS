## Four distinct lanes
| Lane | Scope | Current permission |
|---|---|---|
| **Testing** | isolated CI, mocked offline UI, negative security checks | owner/local only; no external runtime access |
| **Proposed** | source diffs, design prototypes, QA, audit receipts | read-only review; no automatically granted services |
| **Beta** | one invited, consenting outside tester, read-only in-chat cockpit; verified Android candidate if separately accepted | **BLOCKED** pending supported distribution, rights/privacy, live MCP/UI and owner approval |
| **Beta LTS** | pinned known-good beta baseline, maintenance, compatibility, rollback | **FROZEN CANDIDATE**; NOT a separate stable production release or approved external installer |

**Today’s service policy:** long-term servicing uses the **beta baseline** until an independently signed, versioned, installed, upgraded and approved maintenance release exists. No silent alias to a verified production LTS binary.

## Invite staging checklist (owner actions, not performed by this page)
1. **GitHub:** this public repository is readable without collaborator access. If review/issue/commit rights are needed, verify the tester’s GitHub **username** separately and grant the least privilege that supports the task. Do not infer identity from email.
2. **Google AI:** share a specific approved Google AI Studio Build app with the intended viewer/editor role, or grant narrowly scoped Google Cloud project IAM access. Neither a Google Drive link nor this repository grants AI Studio or cloud-project membership. Limit billing and API access.
3. **OpenAI:** if needed, invite to a dedicated low-privilege OpenAI Platform project; ChatGPT plugin access is **separate**. Confirm an eligible workspace/plugin sharing channel, underlying ChatGPT Site viewer permission where applicable, and external user install. Personal private Project Hydra does not gain sharing just because a link exists.
4. **Owner review:** approve an exact candidate and privacy/rights scope **before** sending any invitation. Keep tester identifiers, access links/tokens and feedback in a private channel, not GitHub.
5. **Acceptance:** fresh ChatGPT installation, tool scan, the actual in-chat cockpit, Lum/pet/scene UI, portrait and landscape, read-only confirmation, opt-out path, reproducible bug reporting, and rollback receipt. Android/Godot acceptance separately.
