# Plush Stage · 4 × 4 × 4 Development and Verification Matrix

**Scope:** Family creative toy. Prototype-only, no public distribution or private family content.

## 4 creative pillars (rows)
1. Film: original iPhone footage, local preview, camera permissions and shot list.
2. Voice: class-compliant Yeti capture testing, local voice clips, and narration synchronization.
3. Game: four editable character slots, scene progression, stage moves, and small replayable chapters.
4. Mix: CapCut interoperability by ordinary exported media, approved music links, subtitles and sharing through an adult.

## 4 creative operations (columns)
1. Ingest: choose original source media without uploads.
2. Compose: edit scene title, description, cast and actions.
3. Play: run the story board as a stage/game.
4. Export: save the JSON shot plan; in later releases, opt-in audio/video projects.

## 4 release and evidence states (depth)
1. Source: code parsed/read back, consent and permissions declared.
2. Bench: Android/Samsung browser smoke, iPhone browser file picker and UI proof.
3. Hardware: actual named microphone/clicker/USB device enumerated and captured, no identity guesses.
4. Distribution: correct signed target, private family test, privacy/rights review, explicit human approval.

A release candidate must have evidence for the affected combinations. 4 × 4 × 4 = 64 traceable cells; it does not claim 64 passing tests.

## Device reality and nonnegotiable boundaries
- iPhone: first-class filming, microphone testing and Safari PWA target. Mac DMG only applies to Mac helper apps; iPhone native apps are .ipa and require signing/provisioning. Safari Add to Home Screen supports a low-friction target.
- Samsung Tab S10 Lite: development and testing surface. Root status is *not* verified; canonical historical device document reported stock/unrooted. Do not assume privileged USB access.
- USB Yeti: class-compliant mic candidate. Test the actual USB cable, device power, adapter and which iPhone app uses that input. For Lightning, a Lightning-to-USB3 camera adapter and external power might be needed; for USB-C, a data-capable hub or adapter may suffice.
- Generic camera: unknown hardware. Label/photo/USB VID:PID/SoC first; no custom firmware flashed from guesswork.
- Samsung Odin/Heimdall flashing: **separate adult-only repair lab for specifically supported Samsung devices**. No iPhone firmware via Odin; no camera firmware via Odin without manufacturer-proved compatible protocol.
- Music: do not rip YouTube content. Use own audio, permissioned Creative Commons, or rights-cleared soundtracks. YouTube links may be embedded via official player for reference, not mixed into downloadable renders.
- Age-appropriate AI: no child's ChatGPT login, automated headless website session, unsupervised unfiltered model access or telemetry. Any future local Ollama/AI assistant must be parent-controlled, evaluated, and limited to creative tasks.
- Preserve raw media originals and native CapCut sources externally. Never commit family footage, recordings, or personal identifiers to public GitHub.
- Preserve the existing LuHm-OS quarantined agents, unchanged release signing, and approval gates. Source branch is a draft proposal, not Crown.

## Manual first playtest
1. Open `labs/plush-stage/index.html` on Samsung in a local Python HTTP server; check 16 cards and 4 action buttons.
2. Rename plush character, save a scene and replay it; confirm progress increments without errors.
3. Choose an own-video MP4/MOV: confirm local preview and absence of upload.
4. Export storyboard JSON. Reload page, import JSON, verify names and scene state.
5. On iPhone: test responsive layout, file import, Safari home-screen behavior from a separately reviewed HTTPS host.
6. Test microphone input on a secure origin (Safari/Chrome may vary). Only after this test: compare actual Yeti mic audio with built-in iPhone mic.
7. Confirm the imported video and microphone recording never leave the device except via explicit file export.
8. Request adult release review after real device receipts. Do not claim store submission, signing, or iPhone compatibility before it happens.
