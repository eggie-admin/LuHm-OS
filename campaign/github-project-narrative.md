# LuHm OS

## Conversational engineering with receipts

LuHm OS is an experiment in making serious software development conversational without surrendering source control, deterministic proof, or human authority.

The operator can work in natural language. Behind that interface, the project uses Python 3 control-plane logic, JSON contracts, exact source identities, Git history, bounded agent roles, CI receipts, and explicit promotion gates.

The governing rule is simple:

**AI proposes. Policy authorizes. CI proves. Human promotes.**

## What makes the project unusual

A substantial amount of LuHm OS has been directed from a Samsung phone while walking around and using conversational AI as the operator interface.

The point is not that AI can type code. The point is to explore how much of an engineering workflow can become conversational or no-code/low-code while preserving the parts that make engineering trustworthy:

- exact source identity
- small mutation scopes
- deterministic audits
- provider boundaries
- explicit UNKNOWN states
- reproducible receipts
- human promotion authority

## Current architecture

OpenAI is the preferred conversational headquarters. Google AI is a high-capacity secondary capability provider. GitHub is the source forge and CI evidence gate. Cloudflare is the future public traffic perimeter. Samsung is the field-development subsidiary.

None of those vendors owns project truth or Crown authority.
