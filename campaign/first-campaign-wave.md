## Master story

LuHm OS is an experiment in making serious AI-assisted engineering feel conversational without surrendering technical truth.

The project is deliberately unit-oriented. Each problem is narrowed, bound to an exact source identity, given a small authority envelope, and required to produce receipts before promotion. When a tool, provider, device path, or integration breaks, the project prefers the smallest proving workaround over a dramatic rewrite.

A substantial portion of the work has been directed from a Samsung phone through conversational AI sessions. The phone acts as an engineering cockpit while GitHub provides source history and CI receipts, Python 3 owns deterministic control-plane logic, and provider output remains candidate evidence until reconciled.

The result is neither "AI magically built an operating system" nor ordinary point-and-click automation. It is a no-code/low-code operator layer over conventional software engineering: intent is expressed conversationally, tools perform bounded work, CI proves exact-source properties, and the Professor retains final authority.
